# Soil Moisture Sensor Build

To finally get out of the twice-daily hand-watering routine, Dev started
building the soil moisture sensor for the greenhouse, using the spare
Raspberry Pi that normally sits on the garage bench. The plan is for the
Pi to read moisture levels from probes in each row and trigger a small
pump once levels drop below a threshold, instead of relying on Dev
remembering the evening round.

Dev got the idea for the soil moisture sensor from Mia's lumber-drying
notebook out in the workshop side of the garage. Dev figured if tracking
moisture over weeks was enough to tell Mia when a board was safe to cut,
the same approach, watching a trend instead of one snapshot, would keep
the pump from overreacting to one hot afternoon and overwatering the
peppers.

Wiring the probes has been slow going, mostly because the jumper wire
tray on the bench turned out to be missing the lengths actually needed
for reaching the far row.
